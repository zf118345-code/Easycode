# EasyCode 测试 Harness

状态：`Approved`（验证模型、首版范围与放行证据类型已冻结；基线硬件和非架构性能阈值由首轮实测登记）

最近修订：2026-09-01

## 1. Harness 是什么

Spec 定义“系统必须做什么”；Harness 是持续证明系统确实做到的执行环境。它不仅是测试命令，还包括固定样例项目、ProgramDocument 生成器、平台与扩展替身、真实宿主、证据目录、性能预算、故障注入和发布门。

Harness 必须回答：

1. 哪条需求被哪个验收与测试覆盖？
2. 测试使用什么构建、环境、数据集和扩展版本？
3. 成功或失败证据在哪里？
4. 哪些能力只由替身验证，哪些已经经过真实 Windows/模拟器/独立 Player？
5. 失败能否稳定重放，而不是依赖用户再次描述？

## 2. 追踪链

所有中大型功能使用以下链路：

```text
REQ-功能-编号
→ AC-验收编号
→ TEST-自动/人工编号
→ EVIDENCE-日志/截图/报告
→ 发布门状态
```

报告必须区分自动验证通过、人工验证通过、未验证、失败和环境阻塞；禁止只写“测试通过”。

## 3. Harness 组成

### 3.1 固定项目与数据

- **最小合法项目**：一个入口 ProgramDocument，验证打开、结构命令、保存、编译和运行。
- **未配置语义项目**：包含显式未配置参数、类型错误、引用缺失和平台不支持；验证可定位修复但禁止运行/发布。
- **结构损坏项目**：非法 JSON、未知 Schema 版本、重复稳定 ID 和破损引用；验证只读恢复、明确诊断和不覆盖磁盘旧版本。
- **并发冲突项目**：内存、磁盘和基线 revision 不同；验证比较、重载、覆盖和稍后处理不形成无限 409。
- **结构命令项目**：覆盖插入、移动、复制、嵌套、删除、提取函数、撤销、重做和引用影响。
- **循环控制与显式失败项目**：覆盖跳出最近循环、跳过本轮、循环外非法位置、嵌套条件/目标/异常区域、最终分支执行、项目函数调用边界、显式失败捕获与未捕获诊断。
- **异常区域重试项目**：覆盖策略缺省、默认次数/间隔、瞬时与永久异常、未知异常、正常无结果、耗尽、捕获/最终分支、暂停/继续、取消/停止、副作用无回滚、审核指纹失效和跨平台等价执行。
- **变量生命周期项目**：覆盖局部变量、项目变量会话副本、Player 初始值覆盖、运行期修改、结束释放、重命名和引用修复。
- **全类型值与 Control 项目**：覆盖所有值节点、未提交 Control 草稿、捕获动作和 Player 表单。
- **递归表达式项目**：固定种子生成深链、宽树、平衡树、跨领域嵌套、惰性选择、可选值、集合局部符号、跨目标空间值、最小类型错误、循环和预算边界；记录操作注册表版本与数据集哈希并支持失败树缩减。
- **表达式重构与 Player 项目**：覆盖包装、解包、复制、移动、赋值/函数提取、不可安全提取、撤销重做、参数根/嵌套签名槽、重叠绑定、过期方案和结构注入。
- **资源生命周期项目**：覆盖导入、选择两阶段提交、移动、替换、删除和引用修复。
- **录制与回放项目**：使用固定种子生成 Windows、ADB 与 Android 目标帧序列、目标/方向/尺寸变化、视觉/OCR期望结果和损坏变体；覆盖全部帧、变化帧、诊断、时间线、比较、离线分析、历史 Capture、导出与清理。
- **目录危险操作项目**：在隔离临时根构造空目录、深层树、宽目录树、权限变化、符号链接、Windows 重解析点、Android Provider 越界/不支持与进程中断；验证七项目录函数、作者审核、终端确认和根目录保护。
- **扩展生命周期项目**：项目级、用户级和官方扩展，包含 `easycode-extension.json` v1、`easycode.lock` v1、发布者信任、宿主/目标变体、密封产物、依赖、权限、Worker 故障、引用阻止和发布闭包；另含源码-only、未信任代码、篡改与源码泄漏反例。
- **中立功能扩展项目**：只用于 Harness，覆盖测试函数、测试工作区、命名空间数据、编译/运行贡献、启停回收和发布闭包，不把某个未交付领域功能带入产品 UI。
- **首版范围反向项目**：扫描 IDE、Windows Bundle 与 Android APK，证明不存在页面导航包、Page Model、`页面.*`、页面工作区、扫描 Worker 或拓扑组件；同时验证 `page` 资源目录独立可用。
- **大型合成项目**：至少覆盖 1,000 个函数、10,000 条结构化语句和 10,000 个资源。
- **Android 本机闭环项目**：只使用 Android 已批准函数与扩展，覆盖 Player 表单、真实帧、图像/OCR、点击、滑动、拖拽、长按、文本输入、IDE/Player Capture Session、SAF 文件/目录与递归删除授权、三种帧录制、离线分析、历史 Capture、消息、本地计划、暂停/继续/停止与诊断；同一构建必须能在断开数据线并关闭 IDE/后端后运行。
- **纯本地离线项目**：不声明 LAN/公网能力，覆盖视觉/OCR、输入、等待、文件、项目变量、Control、日志和暂停/继续/停止；发布包在清空预热缓存、阻断公网且关闭 IDE/后端后运行。
- **类型化 HTTP 项目**：只覆盖普通请求的方法、查询、请求头、文本/JSON 正文、文本响应、重定向、超时、TLS、鉴权、限流、服务端错误、敏感值脱敏和显式幂等重试；证明普通请求不接收文件或二进制值，失败只影响当前调用。
- **HTTP 文件传输项目**：使用固定种子生成小文件与大文件，覆盖有序 multipart 文本/文件字段、同名字段、流式上传、流式下载、临时文件、原子提交、旧目标保护、Windows 路径引用与 Android SAF/应用私有引用；注入读取中断、截断响应、取消、超限、磁盘满、权限撤销、进程退出、非 `2xx` 和不支持原子提交的 Provider。
- **局域网消息项目**：覆盖同机、LAN、公网断开但 LAN 可达、LAN 不可达、协调器不可达、收件实例未上线和离线发件箱状态。
- **计划与批量运行项目**：覆盖单次、每日、固定间隔、时区/夏令时、错过触发、重叠、同实例串行、跨实例并行/错峰、Windows 跨项目批次、Android 当前 APK 计划和 LAN 幂等派发。
- **实例配对项目**：覆盖同机自动信任、跨机短期码/二维码、错误码、未知实例、离线已知实例、撤销、密钥轮换和远程启动独立授权。

样例由固定种子生成并记录数据集哈希，不依赖开发者桌面临时文件。

### 3.2 核心与平台替身

- **ProgramDocument 替身/生成器**：稳定 ID、显式未配置值、确定性序列化、revision、结构命令、撤销重做和原子保存。
- **纯值操作注册表替身**：稳定操作/输入槽 ID、版本/哈希、输入输出类型、确定性、空值、求值顺序、来源目标、ECIR 降低和成本元数据。
- **编译器替身**：确定性 ECIR、调试映射、契约/扩展锁输入变化和依赖闭包。
- **Windows 驱动替身**：截图、坐标转换、后台输入成功/失败和物理回退。
- **ADB 替身**：设备发现、帧获取、点击、滑动、输入和断连。
- **Android 本机宿主替身**：MediaProjection 帧、无障碍输入、前台服务、方向/尺寸变化、应用私有文件、系统授权文件引用和权限撤销。该替身只验证契约，不能替代真实设备。
- **目标协调器替身**：Windows/ADB 注册、嵌套作用域、当前目标栈、缓存失效、跨目标空间值拒绝和驱动休眠。
- **Capture Session 替身**：IDE/Player 判别式目的地，覆盖点、区域、截取/选择图片、控件、手势路径、读文件、保存位置、目录、取消、过期、字段/方案 revision 变化、目标变化、并发会话和宿主崩溃。
- **Recorder/Replay 替身**：可控帧时钟、目标片段、全部/变化/诊断策略、有界队列、背压、磁盘保护、损坏索引、分析函数白名单、版本快照、导出与生命周期；替身不能替代三类真实宿主的性能和权限证据。
- **变量运行时替身**：默认值、Player 覆盖、任务隔离、运行期写入和结束清理。
- **文件系统故障注入**：权限不足、磁盘满、外部修改、原子替换失败、目录部分完成、链接/重解析点越界、Provider 不支持、危险确认失效和事务/进程中断。
- **消息服务替身**：同机/局域网投递、多收件人副本、部分已读、离线、断网、确认、等待接收/已读、取消、过期、隔离和非法内容。
- **实例目录与配对替身**：本机注册、公钥身份、短期码、授权范围、已知离线、未知失败、撤销和密钥轮换。
- **计划/Player Hub 替身**：系统计时器、时区/DST、错过/重叠策略、进程启动、批次、错峰、`dispatch_id` 幂等、ACK 丢失、重启恢复和协调端离线。
- **网络与服务故障注入**：阻断公网、保留 LAN、阻断 LAN、DNS 失败、TLS/鉴权/限流/服务端错误、上传读取中断、服务端收取部分上传后断连、下载正文截断/超限、慢速取消、更新/未来授权端点不可达、扩展未声明外连和运行期依赖下载请求。
- **更新仓库与安装替身**：不可变发布、签名元数据、旧清单重放、篡改、断点续传、磁盘不足、作者控制的测试白名单、通道退出不降级、多实例竞争、Windows 双槽和 Android 内容/APK 两种安装结果。
- **监听调度替身**：安全检查点、立即/条件处理、原子接手、FIFO、批次快照、去重、禁止重入、主流程挂起/恢复和崩溃不续接。
- **异常分类与虚拟时钟替身**：稳定异常 ID、瞬时/永久/未知分类，按尝试序号注入失败，精确推进固定间隔/退避，覆盖间隔中取消、暂停冻结和耗尽后的捕获顺序。
- **扩展注册/激活替身**：严格 Manifest/lock、发布者指纹、本机可信代码批准、声明式安全贡献、宿主/目标变体、密封产物、发现、锁定、启停、更新、卸载、依赖、权限、贡献点和引用阻止。
- **扩展 Worker 替身**：超时、取消、崩溃、非法返回、未声明权限、序列化失败和诊断。
- **Bundle Loader 替身**：格式、签名、平台、ABI、权限、许可证、内容哈希、路径穿越和缺失交付闭包。
- **运行生命周期替身**：暂停/继续保持同一运行 ID，停止/取消/进程退出/崩溃后新运行从入口开始。
- **崩溃诊断替身**：动作开始/终态配对、结果未知、稳定语句定位、扩展/消息上下文、脱敏和截图失败。

替身验证确定性逻辑；真实宿主冒烟验证操作系统和设备集成。二者不能互相替代。

## 4. 测试层级

1. **静态门**：Python 编译/类型/lint、Vue TypeScript、ESLint、JSON Schema 和 Manifest 校验。
2. **单元测试**：ProgramDocument 命令 reducer、值 ID 生命周期、递归类型推导、惰性选择、循环检测、摘要有界性、提取合法性、引用索引、函数契约、编译器和驱动算法。
3. **契约测试**：ProgramDocument/命令 API、官方 60 项函数注册表、宿主/目标能力矩阵、纯值操作注册表、错误码、ECIR、Player 签名覆盖槽、`easycode-extension.json`、`easycode.lock` 和贡献点双端一致。
4. **集成测试**：项目保存、结构事务、资源事务、Capture Session、扩展发现—启用—发布、编译执行和 Player 参数覆盖。
5. **浏览器 E2E**：结构化编辑器键盘路径、焦点、折叠、多选、重排、递归值聚焦/面包屑/错误跳转/提取、Control 草稿，以及加载、空、错误、取消、冲突和恢复。
6. **原生宿主冒烟**：Windows 窗口、模拟器、全局热键、原生捕获、物理输入回退、外部 IDE 打开，以及真实 Android 设备上的本机 Runtime、MediaProjection、无障碍输入、权限生命周期和 Capture Session。
7. **发布测试**：独立 `.ecplayer`、无开发机依赖 Windows Player、可安装签名 Android APK、资源/扩展闭包、网络能力报告和 ProgramDocument/扩展源码隔离。完全本地包在清空缓存、阻断公网并关闭 IDE/后端后运行；Android APK 还需断开数据线并使用飞行模式完成样例。
8. **更新测试**：IDE、Player 应用和项目内容分别验证；更新关闭时零外连，开启时验证签名、防回滚、兼容性、暂存、原子切换、上一正常版本、运行方案保留和任务版本固定。Android 内容包与 APK 系统安装必须真机分开验收。
9. **性能与长稳**：结构命令延迟、函数检索、语句/资源虚拟化、热路径、1/2/4/8 实例和 24 小时增长。

## 6. 性能预算与报告

- 普通结构命令视觉反馈一帧内完成；局部 Schema 校验 `<50ms`，跨函数引用/语义校验 `<200ms`。
- 10,000 条结构化语句打开后 `<1s` 可交互；1,000 个函数检索 `<100ms`。
- 10,000 条语句和 10,000 个资源分别验证虚拟化、首屏、滚动和内存上限。
- 未启用扩展不得启动 Worker、扫描、轮询或增加 Player 依赖闭包。
- 空闲 CPU 接近 0、Player SSD 冷启动约 3 秒在基线硬件未冻结前属于观察性 SLO，不作为伪精确放行门。
- 冻结 Player 的 24 小时长稳以最终候选可执行文件和发布包 SHA-256 锁定测试对象；每 30 秒记录完整进程树、RSS、CPU、句柄、线程、进程数和隔离 Player 数据目录字节数，每 5 分钟真实运行一次项目。达到完整时长、零运行失败、进程数始终为 1 且覆盖不少于 288 次任务后，排除前 10 分钟预热，以线性趋势和首末四分位中位数共同判定：RSS 斜率不超过 `4 MiB/小时` 且末四分位不高于首四分位 `32 MiB`；句柄斜率不超过 `1/小时` 且末四分位不高于首四分位 `8`；完整测试中数据目录增长不超过 `64 MiB`。未达到完整时长或缺少任一采样维度只能标记 `incomplete`，不能用短跑外推为通过。

每份性能报告记录构建类型、宿主/系统版本、CPU/SoC、内存、存储、数据集版本/哈希、冷/热条件、样本次数、p50、p95、最差值和明确测量起止点。Android 真机报告另记录设备型号、API 级别、方向、前后台状态、权限状态、电量条件和是否连接数据线。不得只写“感觉更快”。

## 7. 放行规则

- **颜色值与取色**：覆盖固定十六进制输入、系统色板、透明度、IDE 冻结帧取色、Player 发布权限闭包、取消保留旧值和 Android 本机冻结帧取色；不能只以颜色控件截图证明后端采样与持久化已经接通。

- **ProgramDocument**：每个结构命令验证目标 ID、无关 ID 不变、移动保留 ID、复制生成新 ID、撤销/重做对称、确定性 JSON 和原子保存。跨函数复制还必须覆盖集合内部引用重映射、目标作用域不兼容时零写入、源函数不变、目标函数一次撤销、复制剪贴板失败后保留以及跨函数剪切禁用。结构损坏不得被编辑器静默覆盖。
- **编辑器与 Control**：缺少值只能进入已冻结的未配置语义；不存在非法文本草稿。切换、失焦、冲突和关闭不得无提示丢失 Control 草稿。
- **跨前后端功能**：至少一个 API/命令集成测试和一个前端行为测试；只有界面或只有后端不得放行。
- **编译与运行**：相同 ProgramDocument、契约、扩展锁和编译器版本生成字节级或规范化等价 ECIR；IDE 与 Player 执行同一语义。
- **条件模型**：覆盖布尔叶、类型化比较、嵌套 `all/any/not`、顺序短路、类型不兼容、禁止隐式真假转换、禁止副作用条件，以及正常未命中与异常分流。
- **结果与成员**：覆盖简单返回、命名记录、明确空状态、存在性收窄、未收窄成员严格消费、空来源跨 Runtime 结构化失败、字段稳定改名、字段删除影响、动态字典隔离和跨目标空间成员拒绝。

- `[AC-OFF-NET-001]` 显式公网函数的断网、DNS、连接、TLS、鉴权、限流、服务端与超时错误定位当前语句，普通错误处理可继续执行本地步骤。
- `[AC-OFF-HTTP-FILE-001]` 公网阻断、传输中断或远端错误只让对应上传/下载语句失败；上传内容不进入平台诊断，下载原目标哈希不变，Player 外壳与无关本地任务继续工作。
- `[AC-OFF-MSG-001]` 公网断开但同机/LAN 可用时消息继续传输；协调器或 LAN 不可用时保留消息 ID、有效期和真实副本状态。
- `[AC-OFF-UPD-001]` 更新端点不可达不影响 Player 打开或运行/暂停现场；没有已生效最低版本约束时可创建本地任务，已有且超过宽限期的可信策略继续限制新任务；界面不伪报“已是最新”。
- `[AC-OFF-IDE-001]` 本地工具链齐全时 IDE 断网仍可编辑、校验、编译和调试；缺少工具链时指出具体组件。
- `[AC-OFF-EXT-001]` 扩展未声明外连时访问被阻止或发布失败；声明公网的扩展不能获得“完全离线”报告。
- `[AC-OFF-UX-001]` 完全本地任务断网时没有阻塞性错误；每个连接错误说明失败层级、受影响操作和恢复方式。
- `[AC-NET-HTTP-001]` 真实服务覆盖类型化方法、查询、请求头、正文、响应、重定向、超时、TLS、鉴权、限流、5xx、取消和敏感值脱敏；失败不建立 Runtime 全局离线状态。
- `[AC-NET-HTTP-RETRY-001]` 有副作用请求默认不重试；服务端已收到 POST 但响应丢失时不自动生成第二请求。只有作者在外层异常区域启用策略并确认副作用风险后才产生下一次请求，且可以复用业务幂等键。
- `[AC-NET-UPLOAD-001]` 真实服务按原顺序收到文本/文件 multipart 字段、同名字段与一致文件哈希；Windows 和 Android 通过可读 `FileReference` 流式上传，峰值内存不随文件大小线性增长。
- `[AC-NET-UPLOAD-FAIL-001]` 引用失效、授权撤销、读取中断、网络断开、取消以及服务端已收到部分上传但响应丢失时，错误定位实际阶段且 Runtime 不自动发送第二请求。
- `[AC-NET-DOWNLOAD-001]` Windows 和 Android 把 `2xx` 大文件流式写入临时文件并原子提交到可写 `FileReference`，返回字节数与最终文件哈希一致。
- `[AC-NET-DOWNLOAD-ATOMIC-001]` 预置旧目标后注入非 `2xx`、截断、取消、超限、磁盘满、权限撤销、进程退出和提交失败，旧目标哈希不变且没有可见半文件；不支持原子提交的 Android Provider 在联网前拒绝。
- `[AC-NET-FILE-CLOSURE-001]` 发布报告分别定位 HTTP 网络范围、上传读取和下载写入权限；普通请求不接受文件/二进制值，缺少任一函数实现、文件宿主或权限闭包时发布失败且不发生运行期补下载。
- `[AC-NET-LOCAL-TRUST-001]` 同机同用户同产品实例只对普通消息自动信任；跨用户、跨项目和远程启动不能继承该权限。
- `[AC-NET-PAIR-001]` 跨机短期码/二维码完成双向身份建立，错误、过期、重复使用、指纹不一致或拒绝均不留下半配对。
- `[AC-NET-REVOKE-001]` 消息、状态和远程启动权限分别授予/撤销；撤销设备后旧会话、重放和离线队列不能恢复权限。
- `[AC-SCH-TIME-001]` 单次、每日和固定间隔计划在冻结时区/DST规则下得到确定触发，同一到期点最多生成一个 occurrence。
- `[AC-SCH-SERIAL-001]` Windows Hub 能按批次启动多个已安装项目/方案；同实例严格串行，不同实例并行或按配置错峰。
- `[AC-SCH-IDEMPOTENCY-001]` LAN 派发使用稳定 `dispatch_id`；超时、重试、ACK 丢失、Hub/目标重启都不会产生第二个 `run_id`。
- `[AC-SCH-AND-001]` Android 只调度当前 APK 方案，并对省电延迟、强制停止和权限限制报告真实状态；不得展示跨 APK 假能力。

## 9. 证据与资源保护

- 日志、截图、录像和性能报告写入测试产物目录，不塞入长期规范。
- 失败证据保留到问题关闭；通过证据至少保留最近完整基线。
- 重型验证串行；单条命令优先紧凑输出和 `--maxfail=1` 定位。
- 自动化通过不等于真实宿主通过；报告明确证据层级。
- 不通过结束未知进程“解决”性能问题，只清理核验过的重复项目进程。
- `[AC-FUNC-VISION-ACTION-001]` 两个“点击位置直到…”函数在条件初始已满足时均零点击；未满足时只点击给定位置并逐轮读取新帧，出现/消失稳定帧、到期、取消、最后匹配和点击次数在规范 ProgramDocument、Windows/ADB 融合 Runtime 与 Android 本机保持一致。
- `[AC-FUNC-VISION-ACTION-002]` IDE 当前画面测试只执行一次图像查找且不产生输入；发布预检、Windows Player 冻结边界与 Android APK 预检都识别两个新 opcode，缺少帧或输入能力时在运行前阻止。
- `[AC-AUTH-LANG-001]` 同一行内输入器可从函数关键词与结构意图创建候选；确认后只出现普通 ProgramDocument 节点，项目目录不存在可保存意图文本、源码或反向解析缓存。取消、歧义、参数不足和 revision 冲突均零写入。
- `[AC-AUTH-COND-001]` `bool / optional<T> / 数值 / 文本 / 列表 / 字典` 简写分别物化为冻结的显式布尔树，IDE 与两类 Runtime 结果一致；任意记录、引用与 JSON 被拒绝。普通查询失败不进入否则，查询正常无结果才使“有结果”条件为假。
- `[AC-AUTH-CALL-BRANCH-001]` 从条件任务选择一个 `bool` 或 `optional<T>` 查询后，一次命令创建且只创建一条调用、一个类型正确结果绑定和一个相邻条件；运行日志证明查询只执行一次，撤销一次移除全部结构。
- `[AC-AUTH-UNTIL-001]` 通用“执行直到”在初始状态已成立时零动作；否则按“查询—判断—动作—间隔”执行，每轮使用新查询，达到条件、上限、超时、暂停和取消时产生准确终态。生成结构与作者手工搭建的普通 ProgramDocument 编译为等价 ECIR。
- `[AC-AUTH-FSIG-001]` 新增、重命名、重排、删除和改型项目函数参数以及修改返回类型均使用 revision 保护的事务；重命名/重排保留稳定参数与符号身份，已被函数体或调用方消费的参数不得被静默删除或改型；缺失必填参数、默认值不兼容、契约指纹和撤销重做均有覆盖。
- `[AC-AUTH-DISC-001]` 新用户只输入“坐标.”、“颜色.”、“画面.”或自然语言关键词即可发现已存在的偏移、缩放、颜色接近和裁剪能力；目录候选与实际可提交类型一致，不以新增同义函数通过验收。
