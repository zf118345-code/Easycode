# vNext IDE 交互规范

状态：`Approved`（结构化编辑主路径与递归值表达式交互已冻结）

最近修订：2026-08-31

本文件是 [UI 与交互规范](../../design.md) 的 vNext 工作流摘要。

```text
顶部命令与项目状态
┌ Activity ┬ 左侧上下文/函数目录 ┬ 纵向结构化语句 ┬ 右侧检查器 ┐
├──────────┴────────────────────┴────────────────┴────────────┤
│ 问题 / 输出 / 调试 / 测试（按需展开）                       │
└ 状态栏：目标、诊断、保存、运行状态 ─────────────────────────┘
```

左侧负责定位与创建，中央负责顺序和结构，右侧负责当前对象的完整配置。同一动作只保留一个主入口。

## 1. 工作区

- **程序**：项目函数、官方函数和已启用扩展函数；中央编辑当前项目函数。
- **资源**：左侧目录、中间预览、右侧元数据与引用。
- **Player**：左侧字段树、中间实时预览、右侧字段配置。
- **运行目标**：管理 Windows 桌面/窗口、Android ADB、Android 本机测试 Player 和无目标配置；界面明确区分 ADB 目标与手机内 Runtime。
- **运行记录**：左侧录制会话，中间历史帧与虚拟化时间线，右侧比较/分析/版本证据；覆盖三种录制策略、历史 Capture、导出、删除和本机空间管理。
- **计划与实例**：管理本地计划、批次、本机实例、跨机配对与远程启动授权；Windows 可以编排多个已安装项目/方案，Android 只显示当前 APK 方案。
- **问题/输出**：真实诊断、运行事件和恢复动作。
- **发布**：生成 `.ecplayer`、Windows Bundle 或 Android APK，并配置相互独立的 Player 应用更新与项目内容更新；未启用更新时不展示远程发布状态。
- **功能扩展**：只有项目安装并启用真实扩展后才贡献工作区、命令与函数；未启用扩展不得留下占位入口。首个正式版本不提供页面导航工作区或 `页面.*` 函数。

扩展维护从项目设置中的“管理扩展”进入；首版不提供市场、评分或占位插件入口。

## 2. 纵向结构化语句

中央区域投影当前 ProgramDocument，不提供可编辑源码或 Monaco。普通调用默认一行；条件、循环、异常、目标作用域和监听使用缩进、区块标题与作用域轨道。

流程正文使用一套克制的视觉语法：普通语句是内容行；条件、循环、异常和目标切换是统一的范围标题；“那么 / 否则如果 / 否则 / 捕获 / 最后”是范围内的轻量分隔行。只有嵌套内容显示连续作用域轨道，根级不绘制无意义竖线；目标上下文只使用克制的文字颜色区分，不在正文增加解释所处目标的图标，其余控制类型也不建立逐类图标或颜色字典。分支分隔行比语句行更矮，已有分支与“添加分支”操作必须有明确的视觉权重差异，但二者继续作为完整键盘插入目标。

用户界面不并列展示结构类型名和语义摘要。控制结构在目录中使用“如果、重复、尝试、在目标中、收到消息时、设置变量”等可直接理解的短动作；中央只补充会改变理解的真实参数，检查器直接沿用中央标题并只展示可修改字段，不再重复“条件、异常区域、赋值”等内部分类。流程正文采用可扫读的短句骨架：“尝试 / 错误类型时 / 最后”“如果 / 那么 / 否则”。“执行里面的语句”“无论成功或失败”等已经由层级表达的解释不进入常驻正文，只在帮助或无障碍说明中提供。`ProgramStatement.kind` 等稳定类型仍完整保留在模型、命令与诊断中。

必须支持单选、连续/多选、折叠、插入、删除、复制、剪切、粘贴、拖动重排、键盘移动与层级调整、撤销/重做、提取函数、转到定义、查找引用、稳定重命名、断点和运行状态。大型文档使用虚拟化，折叠内容不创建不可见 Control。

复制、延迟剪切、锚点粘贴、批量层级调整与同类参数编辑的详细状态、失败和原子性语义以 [STRUCTURED_BATCH_EDITING.md](./STRUCTURED_BATCH_EDITING.md) 为准。`Ctrl+C` 不得创建副本；`Ctrl+D` 才是立即创建副本。

所有操作提交版本化结构命令。移动保留 `statement_id`，复制生成新 ID；删除或提取前展示引用影响。中央区不承载完整参数表单，避免语句退化成长卡片。

中央编辑器提供共享函数目录驱动的行内快速插入器。选中语句时按 `Enter`，或在任意聚焦语句按 `Ctrl+Enter`，在该语句所属容器的下一位置打开临时搜索行；语句行的插入动作提供等价鼠标入口。分支插入目标从其自身打开时，搜索行位于该分支末尾。空函数直接显示可聚焦的首条语句搜索入口。未选中语句的第一次 `Enter` 只选择语句，不能同时产生写操作。

行内搜索跨控制结构、当前项目函数、官方函数和已启用扩展函数检索当前可用目录，复用左侧函数库的规范化、关键词与匹配逻辑，但保留独立查询状态。输入时只筛选本地目录，不逐键请求后端；候选使用紧凑单列，方向键移动、`Enter` 或单击立即插入，`Escape` 取消并把焦点还给原语句。中文 IME composition 期间的 `Enter` 只交给输入法。候选为空时提供“在完整函数库中搜索”的恢复入口。

快速插入器只是派生命令表面：打开、输入和取消都不得修改 ProgramDocument。确认候选后仍调用现有版本化插入命令，成功后选择新语句并把焦点留在中央；失败、冲突、忙碌或目录暂不可用时保留查询、插入位置和候选，并在原位说明原因。锚点失效时不得静默改到函数末尾。左侧函数库继续负责完整浏览和详情，不得因新增快速入口删除或弱化。

- `[REQ-IDE-INSERT-001]` 左侧函数库与中央行内快速插入器消费同一目录搜索内核；相同范围和关键词产生相同候选集合，新增官方、项目或扩展函数无需修改行内组件。
- `[REQ-IDE-INSERT-002]` 行内快速插入支持鼠标、选中行 `Enter`、任意聚焦行 `Ctrl+Enter`、方向键、确认、取消、焦点恢复和中文 IME；每个可容纳语句的分支行都提供同一款就近 `+` 图标入口，不能要求用户返回左侧函数库；只有确认候选才产生一次可撤销结构命令。
- `[REQ-IDE-INSERT-003]` 普通语句、结构语句、分支和空函数的搜索行必须出现在真实提交位置；失败保留草稿和锚点，锚点失效明确阻止，不自动回退到其他容器。

## 3. 摘要与未配置状态

函数契约提供版本化摘要模板，服务端把固定文字与稳定参数槽分别投影，界面再按当前类型化值生成紧凑说明，例如：

```text
等待 2 秒
等待图像 [缩略图 登录按钮] 出现 → [局部 · 登录结果]
点击 [局部 · 登录结果].中心
```

摘要是流程地图，不是第二个检查器：只保留动作、关键对象和无需额外解释即可理解的重要差异值。超时、间隔、阈值、编码、预处理、完整路径、原始 JSON 与技术定位信息留在右侧。摘要必须在不悬停时成立；若一个值必须依赖浮层才能解释清楚，该值不得进入中央摘要。当前不设置固定参数数量上限，是否过载以真实流程扫读证据复审，不能预先用任意数量裁掉必要语义。

所有摘要参数由同一语义投影器处理：图片引用在参数原位显示固定尺寸缩略图和简短名称，行首不再承担资源预览；自动时间戳图片名在中央显示“未命名图片”，完整资源名仍可在详情取得。变量、目标、控件、文件、窗口、枚举、持续时间、百分比、坐标、区域和集合使用统一的人类表达；动态值文字完全继承语句正文的字体、字号、字重与颜色，只由半方括号标识其语义身份，不重复制造一套文字样式。缺失展示元数据或失效引用显示明确不可用状态，内部 ID 不能作为界面回退。缩略图只加载虚拟列表当前已渲染行并按资源复用请求，加载失败保留同尺寸图片图标和名称，不改变绑定与行高。

官方函数、项目函数和受控扩展消费同一摘要契约与渲染器。扩展只能声明固定文字和已有参数槽，不能提供私有中央组件；未声明摘要时安全回退为规范函数名。可选 `step_label` 只在用户主动添加时显示，不要求每条语句维护“节点名称”。摘要只读，点击语句仍在右侧编辑完整参数。

- `[REQ-IDE-SUMMARY-001]` 全部函数来源使用版本化结构化摘要契约、同一语义值投影和同一中央渲染器；摘要必须单行、只读、无需悬停即可理解，并且不得把内部稳定 ID、完整结构或右侧次要配置复制到中央。
- `[REQ-IDE-SUMMARY-002]` 图片资源在参数槽原位显示紧凑缩略图与可读名称；自动名称、加载、失败和引用失效均保持行高与操作可用，虚拟列表只加载已渲染行并按资源复用请求。
- `[REQ-IDE-SUMMARY-003]` 扩展摘要只能引用本函数稳定参数，未知槽在注册前拒绝；省略摘要的官方、项目或扩展函数安全回退规范函数名，不允许页面级表现扩展。
- `[REQ-IDE-SUMMARY-004]` 具有必填对象、目标、位置、来源或去向的官方函数必须在摘要中展示足以区分实际行为的参数槽；只有零参数函数、全部参数均为不改变基础语义的可选默认值，或规范函数名已经完整表达行为时，才允许只显示函数名。正文、长文本、超时和高级策略仍留在检查器。

范围外：本阶段不提供摘要可视化设计器、多套自动布局算法、第三方值渲染插件、多语言模板、作者侧自动脱敏、摘要质量评分或全状态预览矩阵，也不预设固定参数数量上限。

主工作区排版只使用两级常驻字号：13px 的界面正文（包括标签、列表、元数据、状态和语句摘要）与 15px 的主要工作区/弹窗标题。层级优先通过字重、文字颜色、留白和边界表达；同一行的标题、计数、状态与动作文字不得为了区分层级使用不同字号。欢迎页品牌标题、二维码配对码和移动端为避免浏览器自动缩放而使用的输入字号属于任务性例外，不扩散到工作区组件。界面只使用统一无衬线字体；等宽字体仅用于确实需要逐字符比较的代码、哈希、路径和测量值。

- `[REQ-IDE-TYPE-001]` 主工作区及其侧栏、中央编辑器、检查器、底栏和弹窗的计算字号必须收敛为 13px 与 15px 两档；特殊任务例外具备明确选择器与用途，不允许页面自行新增 10–14px 的相邻字号。
- `[REQ-IDE-TYPE-002]` 同行信息使用同一字号并以颜色或字重表达主次，图标按文字视觉中心对齐；缩放和窄宽度通过截断、换行或布局回落处理，不通过缩小局部文字规避空间问题。
- `[REQ-IDE-TYPE-003]` 中央语句摘要的固定文本、半方括号动态值和步骤备注共享同一行高与文字基线；动态值不得使用居中对齐的独立行内盒，备注不得继承另一套行高。颜色和字重可以表达语义主次，但不能改变同一行的垂直位置。

必填参数没有默认值时，插入命令保存显式 `unset`。语句仍可选择、移动、保存和修复，摘要显示“待配置”，检查器聚焦字段；编译、运行和发布被诊断阻止。不存在括号未闭合、文本无法解析或“上一次合法 AST”状态。

## 4. 函数目录与扩展开发

函数目录使用“项目 / 官方 / 已启用扩展”标签，并按图像、文字、输入、等待、日志等领域分组。普通用户无需区分官方原子与标准函数。

目录父级领域名称承担分组，字号不得小于子项；子函数必须在展开符之后继续缩进，不能因为父级有展开图标而反向靠左。子项直接使用与中央、检查器一致的语义名称，技术限定名只参与搜索和帮助。

- 单击只选择，并在检查器显示待插入参数。
- 双击、Enter、行尾按钮或右键“插入”才执行插入。
- 待插入配置是临时事务；确认后一次创建调用与稳定 ID，取消后丢弃。
- 快速插入使用默认值；缺少默认值的必填参数写入 `unset`。
- 项目函数提供打开、插入、查找引用、重命名和删除；官方函数提供只读帮助和插入。

扩展函数注册后使用同一体验。Python/原生实现只在扩展维护工作区出现；EasyCode 创建/导入骨架、审核契约、运行测试并在 PyCharm、VS Code 等外部 IDE 打开。外部 IDE 启动失败时提供路径检查、重新选择和文件管理器打开。

## 5. 检查器与 Control

选中语句后，检查器优先展示可修改的全部参数、返回绑定和必要结构属性；选中目录函数时配置待插入调用。实现分类、平台列表和长说明进入帮助，不常驻挤占表单。

所有确实存在第三详情栏的工作区共用最右侧活动按钮进行展开和收起；窄屏时该按钮打开覆盖式抽屉。只有“列表 + 主编辑区”的两栏任务页不得为了外观对称制造空第三栏。页面内部不得再重复一套检查器按钮。

返回值只使用一个输入框：留空即不保存，普通名称即新建局部变量，键入 `@` 或 `[` 即显示当前位置类型兼容的已有局部变量。不存在“不保存 / 新建 / 已有”的前置模式下拉。

表单默认值与 placeholder 必须告诉用户最终有效内容或格式：有确定默认行为时直接显示实际语义（例如 `当前设备时区（如 Asia/Shanghai）`），无默认但有格式时显示可填写样例（例如 `HH:mm:ss`），真正阻止运行的字段才标必填。禁止使用“默认配置”“无结果”“请输入内容”这类不能帮助填写的占位语；固定候选仍使用普通下拉，不增加变量或计算模式。

Control 根据类型与契约生成并提交结构命令。自由标量通过一个统一输入器承接直接值、变量、结果和纯值计算，不把它们暴露成三个常驻模式；固定候选参数只显示契约下拉。资源、目标和成员访问使用类型化选择器，纯值计算可以递归组合，并通过摘要、当前层面包屑、折叠、聚焦和可撤销提取保持紧凑。取点、框选、录图、控件和路径捕获由宿主真实能力决定，失败保留字段和请求上下文。

`目录.递归删除` 的检查器把参数编辑与危险审核分开：参数区使用普通 `DirectoryReference` Control，危险区显示函数位置、权限、不可回滚与保护根规则，并保存绑定调用/值树/契约指纹的作者确认。IDE 调试解析出实际 `authorization_root_id` 后还要显示独立运行确认，绑定当前调试配置 revision；授权根、目录绑定或契约变化时相应确认原位失效，运行与发布入口直接禁用并定位该区域。不能用一次全局“我已知晓”覆盖项目内所有调用，也不能用作者审核替代实际执行确认。

检查器区分：Control 未提交草稿、已提交的 `unset`/类型/引用问题、结构命令失败、项目持久化失败。语义诊断不能让检查器只读；字段错误就近显示，系统错误进入问题中心。切换语句时，合法草稿提交，不合法草稿要求修复或放弃。

## 6. 诊断、保存与冲突

诊断使用稳定 `function_id + statement_id + value_id`，必要时附带可读 `field_path`。点击问题后打开函数、展开作用域、选择语句并聚焦具体值 Control，不能只用不可见红条提示。

保存状态为等待保存、正在保存、已保存、存在冲突或保存失败。ProgramDocument 的原子结构命令成功即保存，不存在第三份等待整文档覆盖磁盘的可编辑源码；外部冲突展示本次命令使用的共同基线 revision 与磁盘 revision，并提供重新加载后重交仍保留的 Control 草稿，或保留界面稍后处理。不得提供会抹掉无关外部修改的整文档覆盖入口。已保存版本通过项目历史查看和恢复，损坏 JSON 或未知 Schema 只读恢复，不由 IDE 猜测修复。

## 7. 运行、响应式与验收

运行前冲刷已提交命令，并由同一 Compiler Service 生成 ECIR。存在 `unset`、类型、引用、平台、扩展或资源错误时，运行禁用并提供可定位原因。调试状态按稳定语句 ID 投影；停止、取消或崩溃后不宣称可以续接。

发布检查根据真实调用和扩展权限显示“可完全离线 / 需要本机或局域网 / 需要公网”，并列出造成结论的语句和扩展；在线更新单独列为维护服务，不改变任务运行结论。发布器比较上一不可变版本并明确显示“仅项目内容更新”或“需要 Player 应用更新”及原因。官方托管是默认发布目标，展示作者账号、项目归属、通道、基础配额、使用量与审计；兼容自建源位于高级设置并使用同一签名发布流程。断网时，本地工具链齐全的 IDE 仍可编辑、校验、编译和本地调试；缺少 SDK/依赖时指出具体缺失项和安装动作，不能把工具链缺失描述为项目运行必须联网。

1280×720 为最低完整体验。低于 1100px 时检查器收起为可恢复抽屉；空间继续缩小时先收起侧栏，中央语句保持可用。创建、选择、重排、嵌套、参数编辑和调试均有键盘路径，拖拽不是唯一入口。

放行前必须验证：

- 没有可编辑源码、Monaco 或文本反向导入入口；
- 所有编辑通过可撤销结构命令完成，且无关稳定 ID 不变；
- `unset` 可保存、可修复但阻止编译/运行/发布；
- 递归纯值计算可完整编辑、折叠、聚焦和提取，稳定 `value_id` 不因显示变化漂移；
- 中央投影与检查器引用同一 ProgramDocument；
- 官方、项目和扩展调用通过同一版本化摘要契约与语义投影器生成单行流程说明；图片缩略图位于参数原位，加载失败或引用失效不泄露内部 ID、不改变行高，且中央理解不依赖悬停；
- 保存失败、外部冲突、切换和关闭不无提示丢失模型或 Control 草稿；
- 扩展外部 IDE 流程具有失败恢复、契约测试、启停和发布闭包；
- 任一功能扩展禁用时均满足零入口、零函数、零后台和零 Player 依赖；首个正式版本的可用扩展清单不包含页面导航。
- Android 本机发布入口只有在签名 APK 构建链和真机环境可用时出现；部署、连接、权限、断线和日志状态均有真实后端承接，普通 ADB 目标测试不能显示为本机通过。
- 完全本地项目断网时不显示阻塞性全局错误；显式联网函数、消息协调器、更新或未来授权的失败分别显示真实层级和受影响范围。
- 更新关闭时无远程端点、状态轮询或入口；启用后作者发布、签名、测试/稳定通道、匿名白名单、确定性百分比、暂停/继续/全量和失败恢复都必须有真实服务承接。没有终端遥测时不得展示安装数、成功率或自动回滚状态。

- 计划批次逐条显示真实实例、产品、方案、下次运行和状态；未知实例、已知离线、无远程启动权限、实例忙与目标离线不能共用一个模糊错误。
