# 结构化流程批量编辑规格

状态：`Implemented / Browser-verified / Regression-passed`  
范围：vNext IDE 结构化流程编辑器、Program Service、共享检查器  
非目标：系统剪贴板、跨项目粘贴、跨函数剪切移动、异构函数参数批改、备注批改

## 用户任务

主要用户是需要维护长流程的脚本作者。用户先在中央流程中单选、连续选择或多选语句，再通过标准键盘操作完成复制、延迟剪切、锚点粘贴、层级调整和同类参数批改。成功结果必须可以从流程顺序、选中态、检查器内容和一次撤销中直接观察；失败不得产生部分写入。

错误操作成本为高：部分移动、错误插入位置或只修改一部分参数都可能改变真实执行语义。因此所有会修改 ProgramDocument 的批量动作必须由 Program Service 原子提交，并遵守 revision 冲突检查。

## 复制、剪切与粘贴

- `[REQ-IDE-CLIP-001]` `Ctrl+C` 只把当前选择的顶层语句子树复制到项目级 IDE 内部结构剪贴板，不修改 ProgramDocument。复制内容是操作当时的不可变结构快照，可在同一项目的其他函数中重复粘贴；父语句与其后代同时被选中时，只保存父语句一次。
- `[REQ-IDE-CLIP-002]` `Ctrl+X` 不立即删除语句，而是建立待移动集合。待移动语句保持原位并显示统一的弱化剪切态；`Escape`、切换项目或切换函数取消待移动状态。待移动状态不写入项目。
- `[REQ-IDE-CLIP-003]` `Ctrl+V` 默认粘贴到当前主选中语句之后；选择分支插入行时，粘贴到该分支末尾。复制粘贴生成全部新的 `statement_id`、`value_id`、分支、捕获和自有符号 ID，并保持同一复制集合内部的符号引用关系。
- `[REQ-IDE-CLIP-004]` 延迟剪切粘贴是移动而不是复制，全部稳定 ID 保持不变。锚点位于待移动集合内部，或移动后的结果与原顺序等价时，操作成功但文档不发生语义变化。成功后清空剪切态。
- `[REQ-IDE-CLIP-005]` 复制剪贴板在同一工作区 generation 内跨项目函数有效，切换项目、重连工作区或按 `Escape` 后清除；待剪切集合仍只在源 ProgramDocument 内有效，切换函数即取消。源结构已经失效、选择跨越多个语句容器或目标位于被移动子树内部时，界面给出可恢复说明并保持原文档不变。
- `[REQ-IDE-CLIP-006]` 编辑菜单、命令面板、行内更多菜单和快捷键使用同一命令 ID、启用条件与中文名称。`Ctrl+D` 保留为“立即创建副本”的显式快捷动作，与 `Ctrl+C` 的剪贴板语义分离。
- `[REQ-IDE-CLIP-007]` 跨函数粘贴由目标函数的 Program Service 原子提交：所有语句、值、分支、捕获与复制集合内部声明的局部符号重新生成稳定 ID，项目级资源、目标、变量与项目函数引用保持稳定。目标函数不可见的外部局部变量/参数、非法层级控制或不兼容返回值必须在写盘前整体拒绝；错误说明恢复方式且保留复制剪贴板供作者修正后重试。

## 批量顺序与层级

- `[REQ-IDE-GROUP-001]` 批量上移、下移、删除、粘贴、剪切移动和参数修改均为一次版本化提交、一次保存和一次撤销；任一成员失败时全部失败。
- `[REQ-IDE-GROUP-002]` 批量移动按当前容器中的文档顺序处理，不以鼠标点击顺序重排。移动保持全部稳定 ID。
- `[REQ-IDE-NEST-001]` `Tab` / `Shift+Tab` 对当前选择整体调整层级。所选语句必须来自同一容器且连续；系统在提交前检查目标语句块、父级和循环约束，失败时保持选择并原位说明原因。

## 公共参数批量编辑

- `[REQ-IDE-BATCH-001]` 当至少两条选中语句均为同一 `function_id` 的调用时，右侧共享检查器进入“批量编辑”模式，显示选中数量和该函数契约的可编辑参数；不显示步骤备注、结果绑定、危险审核或其他单语句动作。
- `[REQ-IDE-BATCH-002]` 所选语句的某参数结构相同时显示真实值；不同时显示“多个值”混合态。用户只有主动修改字段时才向全部选中语句写入新值，打开检查器本身不得修改文档。
- `[REQ-IDE-BATCH-003]` 批量值写入复用同一 Program Control 和函数参数契约。每条语句获得独立的值稳定 ID，不能让多个参数根共享同一身份；完整批改为一次原子提交和一次撤销。
- `[REQ-IDE-BATCH-004]` 异构函数、结构语句混选或契约不可用时不展示伪批量表单，而显示选择范围说明和恢复建议。用户可继续复制、剪切、移动或删除该选择。

## 状态与可访问性

- `[REQ-IDE-BATCH-A11Y-001]` 剪切态、复制成功、粘贴结果、批量编辑范围和失败原因进入 `aria-live`；视觉状态不能只依赖颜色。快捷键不在文本输入、组合输入或模态编辑器中截获。
- `[REQ-IDE-BATCH-A11Y-002]` 提交后主选择跟随粘贴或移动后的语句集合；撤销后仍可用键盘继续浏览。忙碌、只读、运行锁和 revision 冲突时所有入口共享同一禁用与恢复语义。

## 验收清单

1. `abcdef` 中复制 `cde`、以 `e` 为锚粘贴，得到 `abcdecdef`，复制动作本身 revision 不变。
2. 剪切 `cde` 后分别以 `a / b / c / d / e / f` 为锚验证 `acdebf / abcdef / abcdef / abcdef / abcdef / abfcde`，且每次只有粘贴时发生一次 revision 变化。
3. 复制包含结果声明和后续结果引用的多语句集合，粘贴集合内部引用指向新声明；原集合引用不变。
4. 批量 `Tab`、`Shift+Tab`、移动、删除及同类参数修改分别只需一次撤销即可完整恢复。
5. 混合值打开批量检查器不写入；修改一个公共参数后全部选中调用取相同语义值，但 value ID 各自唯一。
6. 菜单、命令面板、行菜单和快捷键完成真实浏览器键盘旅程；屏幕阅读器状态文案与焦点回归通过检查。
7. 在函数 A 复制普通语句或包含“声明 → 使用”内部引用的连续集合，切换函数 B 后粘贴成功；A 不变、B 只产生一个撤销条目且内部引用指向新声明。
8. 只复制依赖 A 外部局部变量/函数参数的语句，在 B 粘贴时整体拒绝并保留剪贴板；切回 A 仍可粘贴。跨函数剪切、跨项目复制均不可用。
