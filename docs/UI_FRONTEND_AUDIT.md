# EasyCode 前端入口与后端承接审计

> 审计日期：2026-08-25  
> 结论：前端核心功能均有真实数据或 API 承接；插件中心为唯一明确静态占位，已删除。复杂低频能力已从常驻侧栏迁移到中心工作台。


## 2. 入口决策

| 原入口/内容 | 决策 | 原因 |
| --- | --- | --- |
| 插件中心 | 删除 | 只有静态演示数组，无安装、查询、权限或后端路由；用户明确暂不需要 |
| 能力库左侧常驻入口 | 移入中心开发工具 | 列表 + 契约 + 创建属于复杂工作，280px 侧栏不足 |
| 运行服务左侧常驻入口 | 移入中心开发工具 | 六个领域、多个表单和记录列表需要横向空间 |
| 顶部绿色“从当前节点执行” | 删除 | 与运行菜单、F5 和调试条重复；常驻主按钮会制造误启动压力 |
| 空闲调试工具条 | 条件显示 | 空闲时没有辅助价值，运行/暂停时才出现 |
| 状态栏 `UTF-8`、`Vue 3.5` | 删除 | 不帮助脚本编辑和运行决策 |
| 状态栏完整项目路径 | 改为项目名 + Tooltip | 路径过长，且与项目上下文重复 |
| 状态栏重复执行/保存状态 | 合并 | 执行状态保留一处；保存状态在命令栏呈现 |
| 资源树导入/模板独立图标 | 收入“更多” | 低频动作，不应挤占项目主工具栏 |
| 节点分类 | 使用可搜索大纲、筛选、小地图与自动布局 | 不再引入会占据画布、增加空间判断成本的视觉区块 |
| Player 六个平级运维按钮 | 环境自检直达，其余收入“更多” | 环境自检是运行前高价值动作；其余低频 |
| Player 标题状态 Tag + 状态条 | 去掉标题 Tag | 同一状态重复两次 |
| 变量三段手风琴 | 标签页 + 跨分类搜索 | 减少纵向层级、卡片堆叠和说明断裂 |
| 检查器左右挤压表单 | 容器响应式混合布局 | 窄栏上下布局可读，宽栏才使用双列 |

## 4. 假数据与占位审计

### 已删除

- `PluginMarketPanel.vue` 内的 OCR/云同步/通知静态插件数组。
- Activity Bar 中的插件入口和构建产物依赖。
- About 中硬编码的 `v2.2` 版本提示。
- 状态栏中的 `Vue 3.5`、`UTF-8`。

### 真实但需正确表达

- 能力库三类数据来自后端发现结果，不是展示样例。
- 运行服务计数、消息、租约和离线队列来自项目/Player 独立数据库。
- Player 性能指标来自运行状态；没有指标时整条隐藏。
- 系统变量是运行时契约，不是当前瞬时值，因此 UI 显示“运行时提供”而不是伪造值。

### 空状态规则

- 后端返回空：说明当前没有对象，并给出唯一合理下一步。
- 后端请求失败：保留错误信息和重试，不回落到示例数据。
- 仍在加载：显示加载状态，不先显示 `No Data`。
- 内部字段名不得直接暴露给用户，例如 Player 空表单不再显示 `form_schema`。

## 5. 页面级检查结果

| 页面/区域 | 主要问题 | 已采用方案 |
| --- | --- | --- |
| 欢迎页 | 基础结构合理 | 保留三入口；不增加营销和统计卡片 |
| 顶部 | 菜单、模式、工作面板、运行按钮并列拥挤 | 单层全局命令栏，移除模式、面包屑和快速运行 |
| 项目资源 | 图标过多、文件夹与树脱节 | 三入口、低频更多、文件夹树层级、中性节点图标 |
| 变量 | 手风琴卡片过高、说明断行 | 扁平行、标签页、跨分类搜索、悬停操作 |
| 检查器 | 标签和值横向挤压、信息层级弱 | 节点摘要、容器响应式、固定底栏、自动保存提示 |
| 能力库 | 窄侧栏详情过小 | 中心双栏工作台 |
| 运行服务 | 六类功能挤在窄栏 | 中心工作台，保留领域标签 |
| 日志 | 功能真实 | 保持底部辅助面板，不进顶栏 |
| 捕获 | 原生热路径与 Vue 业务层边界合理 | 原生截图交互；Vue 复用资源管理器 |
| Player | 顶部工具过多、状态重复 | 运维分级、状态单点、响应式纵向布局 |

## 6. 已知工程风险（不伪装成 UI 缺陷）

- Element Plus vendor 包当前约 810KB（未压缩），属于首屏体积风险；IDE 本地运行影响可控。后续若欢迎页冷启动成为瓶颈，可按入口按需注册组件，而不是为追求数字重写整个 UI 库。
- 若节点达到数百个，资源树仍需正式虚拟化；当前结构已经为扁平行和树分组，后续可替换渲染器而不改变交互。
- 测试环境仍输出部分 Element Plus 未 stub 警告；不影响生产构建，但测试基建应逐步统一全局 Stub 以提高日志信噪比。

## 7. 验收基线

- `npm run build` 同时产出 IDE、Player、Capture。
- 所有 Vitest 通过。
- API 合约测试确认前端调用路径都有后端路由。
- 画布 E2E 覆盖创建、连线、多选、拖动、复制粘贴、自动保存和左侧工作区导航。
- 浏览器视觉检查覆盖 1280×720、1920×1080 和窄窗口；属性栏单独覆盖 320/420/520/620px。
- 不存在 PluginMarketPanel 构建块或插件入口。
