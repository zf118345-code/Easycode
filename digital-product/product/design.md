# EasyCode 1.0 Authoring Design

The central editor remains a semantic projection of `ProgramDocument`. A single inline composer accepts either a function search or a short structural intent. The right inspector remains the complete truth surface. Project-function contracts are edited from the function header because they describe the current function, not an individual statement.

Condition shorthand is displayed in the shortest human form but stored as an explicit typed predicate. Function calls selected inside a condition task are materialized as a visible call and adjacent condition in one transaction. Generic “execute until” is materialized as an ordinary bounded loop with one query per iteration and an explicit break.

No screen introduces a source file, parser-owned document, hidden call graph, or Runtime-only macro.
